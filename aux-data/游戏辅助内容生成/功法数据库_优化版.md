# 功法数据库（优化版）

## 设计理念
1. **五行克制**：金克木、木克土、土克水、水克火、火克金
2. **克制加成**：攻击被克制属性敌人时，最终伤害+20%
3. **被克减伤**：攻击克制自身属性敌人时，最终伤害-15%
4. **功法实质化**：功法属性直接影响战斗中的五行克制效果

```
攻击方：天罡剑诀（金系）+ 顶阶法宝
防御方：木灵神功（木系）+ 高阶法宝

计算过程：
1. 基础攻击：1000
2. 功法加成：+100（每层）× 10层 = +1000
3. 法宝加成：1000 × 150% = +1500
4. 总攻击：3500

5. 五行克制：金克木，伤害+20%
6. 克制后攻击：3500 × 1.20 = 4200

7. 防御方防御：1500
8. 最终伤害：4200 - 1500 = 2700

对比：如果没有五行克制加成，伤害仅为 3500 - 1500 = 2000
五行克制使伤害提升了 35%！
```
