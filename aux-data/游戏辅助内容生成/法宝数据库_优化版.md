# 法宝数据库（优化版）

## 设计理念
1. **指数增长**：每提升一个小等阶，数值增长50%；每提升一个大等阶，数值翻倍
2. **百分比加成**：法宝属性以百分比形式加成，体现等阶碾压
3. **法力消耗挂钩**：消耗与玩家法力上限挂钩，体现"法力深厚"优势
4. **等阶碾压**：筑基期打炼气期是碾压级，法宝差距同样如此

## 法力消耗计算公式

```
实际法力消耗 = 玩家法力上限 × 等阶法力消耗%
```

**示例**：
- 玩家法力上限：10,000
- 使用顶阶法宝（法力消耗18%）：10,000 × 18% = 1,800点法力
- 使用通天灵宝（法力消耗50%）：10,000 × 50% = 5,000点法力

**设计理念**：
- 法力深厚的修士可以频繁使用高阶法宝
- 法力浅薄的修士使用高阶法宝会迅速耗尽法力
- 体现了"法力深厚"的战略优势
