# 通天灵宝数据库（唯一性版）

## 设计理念
1. **全服唯一**：每件通天灵宝全服仅存一件，获取后其他玩家无法获得
2. **独特效果**：每个灵宝都有独特的Effect_ID，效果独一无二
3. **极难获取**：不进入常规掉落表，需完成特定任务或击败特定BOSS
4. **法则之力**：每件灵宝都关联一种天地法则

## 通天灵宝机制

### 获取方式
- **世界BOSS掉落**：击败世界BOSS有极低概率掉落
- **天道任务**：完成天道发布的特殊任务
- **天劫渡劫**：渡劫成功后小概率获得
- **上古遗迹**：探索上古遗迹极低概率发现

### 唯一性机制
- **全服唯一**：每件灵宝同时只能被一名玩家持有
- **绑定机制**：获取后绑定，无法交易
- **掉落机制**：持有者被击杀后，灵宝有30%概率掉落
- **回收机制**：持有者弃坑30天后，灵宝自动回收

## 数据库设计建议

### 掉落表设计
```sql
-- 通天灵宝不进入常规掉落表
-- 单独建立通天灵宝获取记录表
CREATE TABLE supreme_treasure_acquisition (
    id INT PRIMARY KEY,
    effect_id VARCHAR(20) UNIQUE,  -- 如 'SUPREME_001'
    treasure_name VARCHAR(50),
    current_owner VARCHAR(50),     -- 当前持有者
    acquisition_time DATETIME,
    acquisition_method VARCHAR(100),
    is_active BOOLEAN DEFAULT TRUE
);
```

### 唯一性检查
```python
def check_supreme_treasure_available(effect_id: str) -> bool:
    """检查通天灵宝是否可获取"""
    treasure = db.query(SupremeTreasure).filter_by(effect_id=effect_id).first()
    return treasure.current_owner is None

def acquire_supreme_treasure(effect_id: str, player_id: str) -> bool:
    """获取通天灵宝"""
    if not check_supreme_treasure_available(effect_id):
        return False
    
    treasure = db.query(SupremeTreasure).filter_by(effect_id=effect_id).first()
    treasure.current_owner = player_id
    treasure.acquisition_time = datetime.now()
    db.commit()
    return True
```
