# COMPLETION_REPORT_TEMPLATE

## 目的

每轮完成报告必须完整、可审查、可交给 Codex 复核。

## 完成报告必须包含

1. 当前分支
2. 当前 commit
3. 本轮任务目标
4. 实际完成内容
5. 修改文件列表
6. git diff --name-status
7. git diff --stat
8. git status --short
9. 是否有 deleted 文件
10. 是否有未跟踪临时文件
11. 是否误建错误路径
12. 玩家路径说明
13. 测试结果
14. compileall 结果
15. smoke_test 结果
16. 接口实测结果
17. 前端 JS 检查结果，若涉及前端
18. 浏览器验收结果，若涉及玩家流程
19. simulation 结果，若涉及数值/收益/消耗
20. 是否有 P0/P1
21. 是否可以提交
22. 是否可以 push
23. 是否可以交给 Codex 审查
24. 下一步建议

## P0/P1 判断

P0：
1. 项目无法启动
2. 数据损坏
3. main 被污染
4. 关键接口不可用
5. 核心行为无法执行

P1：
1. 玩家任务卡死
2. 玩家无法退出或放弃阻塞状态
3. 原有核心功能回归
4. action_type 错误
5. 生活技能形成无限循环
6. 探索核心地位被破坏
7. 旧宗门任务污染新宗门
8. 玩家可见严重英文影响理解
9. 测试失败

## 禁止完成报告

如果没有以下内容，不允许标记完成：

1. git 状态
2. 测试结果
3. 是否 P0/P1
4. 是否可提交
5. 是否可交给 Codex 审查

## 标准结尾

完成报告最后必须明确回答：

1. 本轮是否完成？
2. 是否有 P0/P1？
3. 是否建议提交？
4. 是否建议 push？
5. 是否需要 Codex 审查？
6. 是否需要用户人工验收？
