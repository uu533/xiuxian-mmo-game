# QUEST_ANTI_DEADLOCK

## 目的

任何任务系统、宗门任务、每日任务、悬赏任务、委托任务、秘境任务，只要会占用玩家任务槽，就必须防止玩家卡死。

## 必查问题

任何任务改动必须检查：

1. 玩家如何领取任务？
2. 玩家在哪里看到当前任务？
3. 玩家如何理解任务目标？
4. 玩家如何推进任务？
5. 玩家如何完成任务？
6. 当前版本是否真的存在完成入口？
7. 如果任务需要捐献，是否有捐献 / 上交 / 完成按钮？
8. 如果任务需要材料，材料是否真实可获得？
9. 如果任务需要击杀 / 探索 / 修炼，当前行为是否能推进进度？
10. 如果任务无法完成，玩家能否放弃？
11. 放弃任务有什么惩罚？
12. 惩罚是否会导致负数或异常状态？
13. 玩家退出宗门 / 组织 / 地图 / 阵营时，当前任务是否会清理？
14. 当前任务是否会污染新宗门 / 新阵营 / 新角色？
15. 同时只能接一个任务时，是否有取消、放弃或替换规则？
16. 是否会生成当前版本无法完成的任务？
17. 任务是否绑定正确宗门 / 阵营 / 角色状态？
18. 前端显示与后端校验是否一致？
19. 完成或放弃后是否刷新角色状态？
20. 完成或放弃后是否写入日志？

## 硬规则

如果任一问题没有答案，不允许提交。

如果任务系统只能接一个任务，必须提供：

1. 完成入口
2. 放弃入口
3. 放弃惩罚
4. 退出组织时清理规则
5. 异常任务自动清理或明确错误

## 禁止行为

禁止只实现领取任务，不实现完成入口。
禁止只实现任务配置，不检查玩家是否能完成。
禁止生成当前版本无法完成的任务。
禁止让玩家只能通过退出宗门来解除卡死。
